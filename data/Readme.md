# Data from "Unified Cross-Modal Image Synthesis with Hierarchical Mixture of Product-of-Experts"



#### Data description

All the MR data was registered with the pre-dura ultrasound and resampled in the ultrasound space.

Note: The ReMIND2Reg dataset has been resampled in the original MR data.
